# TaskFlow 1.0 — Gerenciador de Tarefas

O **TaskFlow 1.0** é um gerenciador de tarefas desenvolvido em Python, executado pelo terminal e com armazenamento de dados em JSON.

O projeto foi criado com o objetivo de praticar lógica de programação, funções, estruturas de repetição, tratamento de erros, manipulação de arquivos e organização de código em módulos.

## 🚀 Funcionalidades

- **Adicionar tarefas:** cadastrar tarefas com título, descrição, prioridade e prazo.
- **Listar tarefas:** visualizar as tarefas cadastradas.
- **Buscar tarefas:** localizar uma tarefa pelo seu ID.
- **Editar tarefas:** atualizar as informações de uma tarefa existente.
- **Concluir tarefas:** alterar o status de uma tarefa.
- **Excluir tarefas:** remover tarefas cadastradas.
- **Estatísticas:** visualizar a quantidade de tarefas pendentes e finalizadas.

## 🛠️ Tecnologias utilizadas

## ⚙️ Como executar

**1. Instale o Python 3**

Caso ainda não tenha o Python instalado, baixe-o pelo site oficial:

https://www.python.org/downloads/

**2. Clone o repositório**

Depois entre no projeto no GitHub,  e execute:

```bash
git clone //github.com/Daniel-Lucas-do-Nascimento/Taskflow-1.0
```


**3. Acesse a pasta do projeto**

```bash
cd TaskFlow
```

**4. Execute o programa**

```bash
python main.py
```

No Windows, se necessário, utilize:

```bash
py main.py
```

## 💾 Armazenamento de dados

O TaskFlow utiliza um arquivo JSON para armazenar as tarefas cadastradas. Dessa forma, os dados podem continuar disponíveis entre execuções do programa.
